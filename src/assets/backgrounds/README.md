# Plantillas de fondo

Copia aquí imágenes o videos para usarlos como fondo de TimeBox Hub.
Aparecen automáticamente en **Perfil → Fondo de pantalla → Plantillas** (no hay que tocar código).

- Imágenes: `.jpg`, `.jpeg`, `.png`, `.webp`, `.avif`, `.gif`
- Videos: `.mp4`, `.webm` (se reproducen en silencio y en bucle)
- El nombre que se muestra sale del archivo: `noche-en-tokio.mp4` → «Noche en tokio».

Recomendaciones:

- Imágenes de al menos 1920×1080 px; WEBP pesa mucho menos que PNG.
- Videos cortos (10–30 s) en bucle, 1080p, idealmente < 15 MB (puedes comprimirlos con HandBrake).
- Si un fondo es muy brillante, usa el control «Atenuación del fondo».
